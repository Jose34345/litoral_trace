# P0 Shipment Workspace Implementation Plan

> For agentic workers: execute inline with superpowers:executing-plans and test-driven-development.

**Goal:** Present Review, Documents and Package as one coherent workspace without changing authority.
**Architecture:** Existing Jinja/HTMX routes, review filters and PDF inspector. Compact source-driven summary with HTMX OOB replacement; preserve old anchors, audit details and gated exports.
**Tech Stack:** Python 3.11, Jinja2, existing CSS/JS and pytest; no dependencies.
**Spec:** Authorized P0 sprint, delivery 4; original request retained outside Git.

## Constraints and alternatives
Reuse existing sections and per-field command handlers. A new client app or second viewer was rejected because it would duplicate authorization and evidence contracts. No global sidebar, regulatory rules, readiness writer, billing, experimental mode, migrations or private data changes.
User specified autonomous execution: routine design/implementation decisions are delegated. Three primary section links; review states become filters; regulatory assessment belongs to Package. Old anchors and tab hooks remain forwarding-compatible. Never infer package readiness from a display count.
