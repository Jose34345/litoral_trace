# Litoral Trace — 90-second U.S. Lacey private-beta demo

## Guardrail

Show only capabilities that already exist in Litoral Trace Assurance. Species/harvest-country statuses in the visual are illustrative fields for the U.S. hypothesis; do not present them as a completed Lacey rules engine. Do not show or claim a live ACE/LAWGS integration.

## Format

- 16:9 screen recording or motion mockup.
- 60–90 seconds.
- English captions always on.
- Voiceover optional.
- No founder intro longer than one sentence.
- End with one CTA: `Test one completed shipment.`

## Storyboard + script

### 0–8 s — Problem
**Visual:** three file cards appear: Commercial Invoice.pdf, Supplier Data.xlsx, Packing List.pdf.

**Voice/caption:**
“Your broker does not receive a Lacey declaration out of thin air. The data often starts in supplier documents.”

### 8–21 s — Existing files, not another form
**Visual:** drag the three files into the Litoral Trace upload surface. Show Evidence Vault / original preserved.

**Voice/caption:**
“Litoral Trace starts with the files your team already has — PDF, Excel or CSV — and preserves the original evidence.”

### 21–36 s — Extraction
**Visual:** extracted-field cards appear with source/confidence. Use neutral examples that LT already supports: shipment/order reference, product, quantity, total amount. Then show the proposed Lacey-specific evidence labels only as beta review targets: species evidence / harvest country.

**Voice/caption:**
“OCR and document parsing turn what is actually present into structured candidates, with confidence and source provenance. Missing information is not invented.”

### 36–52 s — Reconciliation / exceptions
**Visual:** two fields become MATCHED, one REVIEW, one MISSING. Show source names on each field.

**Voice/caption:**
“Instead of another spreadsheet cleanup step, Litoral Trace compares sources and surfaces the exceptions: what matches, what conflicts and what still needs human attention.”

### 52–66 s — Evidence trail
**Visual:** click one extracted field and show source-document/evidence relationship; show immutable-original / integrity concept without exposing real customer data.

**Voice/caption:**
“Every reviewed value stays connected to the document that supported it, so the team can reconstruct the evidence later.”

### 66–78 s — Clear boundary
**Visual:** simple flow: `Supplier files → Litoral Trace review → ACE / LAWGS filing workflow` with a visual gap/no integration arrow claim.

**Voice/caption:**
“This private beta is not filing software and it does not make a legal compliance determination. We are testing the preparation layer before filing.”

### 78–90 s — CTA
**Visual:** landing CTA.

**Voice/caption:**
“We’re looking for three U.S. customs brokers or import teams to test one completed historical shipment. No ERP access. Sensitive fields can be redacted. Test one completed shipment.”

## On-screen copy options

- `Extract what is present.`
- `Do not guess what is missing.`
- `Review exceptions, not every field.`
- `Keep the evidence behind every value.`
- `Before the filing step.`

## Do not show

- a green `LACEY COMPLIANT` badge;
- “automatic filing”;
- an ACE/LAWGS API connection;
- legal-risk scores presented as authoritative;
- fabricated customer logos/testimonials;
- invented time-saving percentages.

## Recording checklist

- [ ] Use only synthetic/redacted documents.
- [ ] No staging credentials, URLs with sensitive tokens or customer names visible.
- [ ] Keep product demonstration to existing LT behavior.
- [ ] Species/harvest-country examples clearly framed as private-beta targets.
- [ ] Captions match spoken claims.
- [ ] Final CTA visible for at least 4 seconds.
